# YuanchuLink

YuanchuLink is an independent technology organization working on software engineering, artificial intelligence, and human-computer interaction.

## Projects

### Linne Ecosystem

A collection of components for building and integrating AI agent systems.

| Project | Description |
|---|---|
| [Rinne](https://github.com/YuanchuLink/rinne) | Agent runtime and SDK |
| [Ars](https://github.com/YuanchuLink/ars) | Capability provisioning and management |
| [Daraja](https://github.com/YuanchuLink/daraja) | Language model integration and management |
| [Mitsu](https://github.com/YuanchuLink/mitsu) | Instant messaging bridge for AI agents |
| [Sutra](https://github.com/YuanchuLink/sutra) | Task, session, and capability orchestration |

Each component is developed as an independent project, with its own documentation and licensing terms.
